# 마스터플랜 v0

> 작성: Opus 5.5 (계획 단계) · 실행 모델 배분은 `모델지침.md`

## 흐름
```
01 시장조사 ──▶ 02 기획 ──▶ 03 사업전략 ──▶ 04 홍보전략 ──▶ 05 BI
 (근거)        (컨셉)       (돈·로드맵)     (데뷔 캠페인)    (이름·비주얼·브랜드북)
   └─ 인사이트 5 ─┘└─ 컨셉 1안 ─┘└─ BM·로드맵 ──┘└─ 캠페인 메시지 ┘
```
각 단계 마지막 산출물(`*_요약.md`)이 다음 단계의 유일한 입력. 다음 단계는 이전 폴더 전체를 읽지 않고 요약만 읽는다(토큰 절약).

## 운영 규칙
1. 단계 시작: 해당 README 작업표를 위에서부터 진행
2. 작업 1개 = 산출물 파일 1개 (`_v0`부터)
3. 단계 종료: 게이트 체크 → `retro` → `00_읽는순서.md` 갱신 → 필요 시 `/compact` 또는 새 세션
4. 컨셉 등 중요 결정은 `00_계획/결정로그.md`에 한 줄 (날짜 · 결정 · 근거 파일)

마감일 미정 → 브리프 기입 후 `team-gantt`로 역산 (AI가 날짜 임의 지정 안 함).
