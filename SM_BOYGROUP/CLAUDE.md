# 아이돌 기획 프로젝트 — 지침

## 시작
- 매 세션 첫 동작: `00_읽는순서.md` 확인 → 「현재 위치」의 단계 README만 읽기
- 진행 현황·이력은 `00_읽는순서.md`에만 기록 (이 파일엔 쓰지 않음)

## 경로
- 계획: `00_계획/마스터플랜.md` · 모델 배분: `00_계획/모델지침.md` · 입력값: `00_계획/브리프.md`
- 단계: `01_시장조사` → `02_기획` → `03_사업전략` → `04_홍보전략` → `05_BI` (각 폴더 README = 작업표)
- 안 쓰는 파일: `_보관함/`으로 이동 (삭제·덮어쓰기 금지)

## 규칙
- 파일명: `산출물_v0` → `v0.5` → `v1` … 닫을 때만 `_최종본`. 날짜·`진짜최종` 금지
- 판본 올릴 때 파일 상단에 「왜 바꿨나」 1~3줄
- 수치는 출처 네 조각(무엇을·몇 개·어디서·언제). 없으면 `(확인 필요)`, 추정은 `(가정)`
- AI가 낸 안은 `(AI 제안)` 표시. 결정은 사용자
- 실존 아티스트 이름·얼굴·목소리·로고 사용 금지 (분석 인용은 출처 표기)
- BI 확정 전 그룹명은 코드네임 `PROJECT-I` 사용
- 단계 종료 = 게이트 체크 통과 + `00_읽는순서.md` 갱신
